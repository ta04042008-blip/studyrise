
初期3人・第1エリア全ゾーン設計

17. 今回の位置づけ

本章は、正式仕様書 v0.2 の下位情報源として、第1エリア《ハルカ》の実装可能な物語構造を定義する。

正式仕様では「エリア > ステージ > ゾーン」が唯一の進行階層であり、ゾーンは敵編成そのものを意味する。本章でも新しい中間階層は設けない。

第1エリアは以下で構成する。

項目	内容	状態
エリア	第七管理圏《ハルカ》	暫定確定
ステージ数	3	暫定確定
各ステージ	4ゾーン	暫定確定
総ゾーン数	12	暫定確定
ボス	JANUS / NEREID / MNEMOS	暫定確定
初期プレイアブル	葉山智也 / 南雲彩乃 / 岡村駆	暫定確定

4ゾーン×3ステージは、正式仕様の「各3〜5ゾーン」の範囲内である。

18. 初期3人の役割

18.1 葉山 智也

物語上の役割

「答えることを恐れている主人公」。

第一固定事故の記憶と公式記録が食い違っており、それを長年「自分の記憶違いかもしれない」と考えてきた。

第1エリアでは世界を救うためではなく、

自分が覚えていることが本当に起きたのか確かめる

という極めて個人的な目的が徐々に強くなる。

戦闘上の個性

万能寄り。

攻撃だけ、守備だけに突出させず、「状況を見て判断する」主人公像と一致させる。

戦闘傾向タグ候補

万能 / 観測 / 安定

固有スキル案

《再検証》

サーチ成功など、「一度得た情報を確認する行動」と相性を持つパッシブ。

具体的な効果値は未確定。

正式仕様では固有スキルは原則1キャラクター1つのパッシブであり、手動使用・問題回答・MP消費は行わないため、この枠内で設計する。

状態：案

初期スペル案

《リフレクト》

敵への直接攻撃ではなく、自分または味方の状況を整える万能系スペル。

智也は「強大な必殺技」を最初から持つ主人公にはしない。

状態：案

19. 南雲 彩乃

19.1 人物像

彩乃は「正しい結果を出すこと」を強く重視する。

迷って行動しない智也に対して、

「間違えるかもしれなくても、今決めなければ何も進まない」

という立場を取る。

序盤では、この姿勢は智也より正しく見える。

しかし後に、

結果だけ正しければ過程は問わない

という考えが、アーカイブ網の整合処理と一部似ていることが浮かび上がる。

彩乃自身もそれに気付いていく。

19.2 戦闘上の個性

攻撃・速度寄り。

迷わず行動する性格を、学力と思考速度を活かす戦闘スタイルに反映する。

戦闘傾向タグ候補

攻撃 / 先手 / 決断

固有スキル案

《即断》

戦闘序盤や、自分のアタック成功を契機に効果を得るパッシブ。

数値・具体効果は要バランス調整。

状態：案

初期スペル案

《ブレイク》

単体攻撃を中心としたシンプルな攻撃スペル。

問題回答なしでMPを使う、正式なスペル枠として扱う。

状態：案

⸻

20. 岡村 駆

20.1 人物像

駆はアーカイブ網そのものに強い興味を持つ。

彼は最初から「機械が悪い」とは考えていない。

むしろ、

人間よりシステムの方が正確な判断をすることもある

と考えている。

そのため敵の行動を知るにつれ、

「なぜ壊れたのか」

ではなく、

「本当に壊れているのか」

と考え始める。

この疑問が、第1エリア後半の重要な転換点になる。

20.2 戦闘上の個性

支援・観測寄り。

戦闘傾向タグ候補

サーチ / 支援 / 思考速度

固有スキル案

《解析癖》

サーチ成功を発動契機とするパッシブ。

駆が「知ること」に執着する人物であることを戦闘にも反映する。

状態：案

初期スペル案

《アクセラレート》

味方の思考速度など、行動順へ関係する支援系スペル候補。

共通Effectとして処理可能な範囲に留める。

状態：案

21. 初期3人の思想構造

3人は単に性格の違う仲間ではなく、「正解」に対する3つの態度を代表する。

人物	序盤の考え
智也	間違えるなら答えたくない
彩乃	正しい結果を出すことが重要
駆	人間より正確なシステムに委ねる方がよい場合もある

この3人が第1エリアを攻略することで、

「誰が正しいのか」ではなく、それぞれの考え方に危うさがある

ことを示していく。

22. 第1エリア《ハルカ》

かつて教育施設、研究施設、住宅設備、水循環設備を一体管理していた第七管理圏。

大固定後、アーカイブ網の保全機構によって閉鎖されている。

現在、主人公たちの拠点に必要な水・設備資源・旧通信路の一部がハルカ側に依存しており、放置できなくなっている。

したがって第1エリア攻略は、

「世界を救う冒険」ではなく「今暮らしている拠点を維持するための遠征」

から始まる。

31. 拠点での物語表示

MVPでは複雑なストーリー演出を追加しない。

拠点イベントは、

背景1枚 + キャラクター立ち絵 + 短い会話

で成立させる。

Stage 1後は「疑問」。

Stage 2後は「対立」。

Stage 3後は「真相の一部」。

という役割を明確に分ける。

自由歩行やイベント専用マップは要求しない。

32. スキル・スペルについての正式仕様監査

正式仕様では、MVPのパーティは1〜3人、最大3人同時戦闘、ステージ中は編成固定である。

また固有スキルは原則1人1つのパッシブであり、ローグライトで取得・変更・強化しない。

各キャラクターはステージ開始時に初期スペルLv1を1つ持ち、挑戦中に追加・強化されたスペルはステージ終了時に初期状態へ戻る。

したがって、本章で提案した《再検証》《即断》《解析癖》および初期スペル名は、正式仕様の枠に入るキャラクターコンテンツ案ではあるが、効果はまだ正式決定しない。

現時点の扱い

* キャラクターの思想・物語役割：暫定確定
* 戦闘傾向：暫定確定
* 固有スキル名：案
* 固有スキル効果：要確認
* 初期スペル名：案
* 初期スペル効果：要確認
* 数値：未設計

33. v0.2終了時点で新たに固定する方針

第1エリアでは、プレイヤーに真相を説明し切らない。

明らかになるのは、

「敵が単に暴走しているわけではない」

「智也の記憶は正しかった」

「アーカイブ網は真実より整合性を優先していた」

「その思想は第一固定事故以前から存在した」

まで。

「誰が大固定を起こしたのか」

「中央とは何か」

「なぜ人間社会は不確実性低減を求めたのか」
